## Decisões

- **APIs oficiais, sem intermediário pago.**
  - YouTube Data API v3: cota diária gratuita, que dá uns 6 envios por dia.
  - API do Instagram com login do Instagram: conta profissional, sem precisar de página no Facebook.
  - Content Posting API do TikTok.

  Todas são gratuitas. Para uso com as próprias contas, nenhuma exige revisão do app antes do primeiro teste; a auditoria só libera posts públicos (YouTube e TikTok) e o uso por outras pessoas.
- **Volta do login no frontend, não numa rota pública do backend.** A rede devolve o código para `/gestao/marketing/conectar`, que já está logada no NordTool e manda o código ao backend com o token da sessão. Assim a varredura de rotas protegidas continua valendo, e o `state` assinado (pessoa, rede e validade de 10 minutos) impede usar a volta do login de outra pessoa.
- **Tokens cifrados com chave própria.** Usa AES-GCM com IV aleatório. A chave vem de `NORD_MARKETING_CHAVE` ou, sem ela, é derivada das chaves JWT, para não exigir configuração nova. Trocar a chave só obriga a conectar as contas de novo. Os erros das redes viram mensagem sem a causa, porque a URL de algumas chamadas da Meta leva o token.
- **Vídeo em partes de 8 MB.** O limite de upload da API (16 MB) continua igual para o resto do sistema. O vídeo fica num arquivo temporário e sai das redes direto do disco: o envio para o YouTube e o TikTok é feito por streaming, sem carregar o vídeo na memória.
- **Instagram por `video_url`.** A documentação da Meta não confirma o envio direto ("resumable") com o login do Instagram. Por isso usamos o caminho documentado para os dois logins: o Instagram busca o vídeo por um link público temporário.
  - É a única rota pública nova, com código aleatório de 256 bits.
  - O link vale só enquanto o vídeo está no servidor (no máximo 2 horas) e serve só o arquivo.
  - A rota foi incluída na lista de rotas públicas da guarda de segurança.
- **TikTok: tenta público e cai para privado.** Os clientes sem auditoria só podem postar privado, então o NordTool tenta público quando pedido e, se o TikTok recusar, posta privado com o aviso. O envio vai em partes de 10 MB, com a sobra na última, conforme a regra da API.
- **Publicação em segundo plano.** O processamento das redes leva de segundos a minutos (o Instagram e o TikTok consultam o status a cada 5 s, por até 5 minutos). A tela acompanha a lista a cada 4 s.
- **Custo.** As APIs são gratuitas. O único gasto possível é a banda do Railway para enviar o vídeo às redes, uma vez por rede, e o disco temporário. Não há serviço novo pago.
- **Kwai fora.** Não tem API pública para publicar nem para ler as métricas.
