# Projeto: nord-tool-frontend

- Repositório irmão: `../nord-tool-frontend`.
- Propósito: aplicação frontend Nord Tool.
- Stack observada: React 19, TypeScript 5.8, Vite 6, React Router 7, Tailwind CSS 3, ESLint 9 e npm.
- Comandos observados no `package.json`: `npm run dev`, `npm run build`, `npm run lint`, `npm test`.

## Orientações

- O frontend poderá ser usado como interface para solicitar alterações em qualquer projeto configurado. Para este repositório, carregue `skills/nord-tool-frontend/` e `steering/nord-tool-frontend/`; o fluxo global de branch/commit/merge está em `policies/git-workflow.md`.
- Preserve TypeScript e os padrões de componentes e estilos já usados em `src/`.
- Confira `package.json` e lockfile antes de alterar dependências.
- Execute `npm run lint` e `npm run build` para mudanças relevantes; use `npm test` quando aplicável.
- Não presuma que integrações ou serviços presentes no ambiente local estão disponíveis em produção; consulte a configuração do projeto.
