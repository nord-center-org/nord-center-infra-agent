# Frontend: implementar funcionalidade

1. Leia `projects/nord-tool-frontend.md` e `steering/nord-tool-frontend/`.
2. Inspecione componentes, rotas, estado e chamadas de API existentes antes de editar.
3. Preserve React/TypeScript e os padrões de UI do projeto; considere estados de carregamento, vazio, erro e sucesso.
4. Mantenha acessibilidade e comportamento responsivo consistentes com as telas próximas.
5. Rode lint, build e testes aplicáveis conforme o steering do frontend.
6. Antes de escrever plano, código ou documentação, crie uma branch baseada no `develop` atualizado. Mantenha nela todo o trabalho até completar o plano e as verificações; não edite, commite, faça push ou integre diretamente em `develop`. Publique a branch, abra PR para `develop` e faça squash merge automaticamente quando CI e proteções exigidas passarem, sem aguardar nova solicitação. Se aprovação humana for obrigatória, deixe o PR aberto.
