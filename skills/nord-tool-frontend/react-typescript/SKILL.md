# Frontend: React e TypeScript

- Preserve os padrões de componentes, hooks, rotas e estilos já usados em `src/`.
- Tipar propriedades e dados de API; evite `any` quando tipos concretos forem viáveis.
- Mantenha componentes focados e estados explícitos; não duplique lógica de negócio em múltiplas telas.
- Confira dependências em `package.json` e lockfile antes de adicionar pacotes.
- Evite inserir conteúdo não confiável como HTML sem sanitização adequada.
