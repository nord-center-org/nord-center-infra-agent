# Frontend: arquitetura

- Stack de referência: React 19, TypeScript, Vite, React Router e Tailwind CSS.
- Confirme `package.json` e a estrutura atual de `src/` antes de decidir onde alterar.
- Preserve a separação já usada entre rotas, componentes, serviços de API e utilitários.
- Trate integração com backend conforme contratos existentes; não invente endpoints.
