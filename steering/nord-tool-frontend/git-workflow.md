# Frontend: fluxo Git

Use a policy global: trabalhar a partir de `develop`, criar branch dedicada, validar, commitar nessa branch e integrar somente em `develop`. `master` espelha produção; promoção para ela ocorre por fluxo de release separado. Os bloqueios do MCP não dependem de proteção nativa no GitHub. `main`, se existir, não é destino automático.
