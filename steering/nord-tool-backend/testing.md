# Backend: validação

- Comandos documentados: `mvn clean`, `mvn install`; execute também `mvn test` quando aplicável.
- Prefira testes focados para regra alterada e build Maven para alterações relevantes.
- Confira configuração de banco e integrações necessárias antes de executar testes que dependam de serviços externos.
- Relate comandos executados e falhas sem afirmar validação não realizada.
