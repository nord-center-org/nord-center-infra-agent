# Backend: arquitetura

- Stack de referência: Java 11, Spring Boot 2.7.15, Maven, Spring MVC, Spring Data JPA e PostgreSQL.
- Confirme o código e o `pom.xml`; o perfil é uma referência, não substitui a implementação atual.
- Preserve separação existente de API, regras de negócio e persistência.
- Alterações de schema devem ser coordenadas com `nord-tool-scripts-sql`.
